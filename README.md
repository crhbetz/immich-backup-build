# Immich Backup

This repo contains a github workflow to build a 1:1 identical copy of the Immich Android app with the package name `app.alextran.immich.backup` and app name "Immich Backup".

It enables the user to install a second copy of the immich app to the same device and user account, to be able to connect to another immich instance, or another immich user, without switching logins. For example, you could have one user where images are shared amongst the family, while another user is there to perform live backup of any image you take on your phone to your immich instance (thus the word "backup" in the app name).
